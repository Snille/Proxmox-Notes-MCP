    Proxmox hosts

    The hosts this instance works with. Each needs an API token; the secret is stored on the server and never shown again.

      How to create the user and token on a Proxmox host

      Run this on the Proxmox host as root. "pveum user token add" shows the token secret once; paste it in the form above. "pvenode cert info" shows the fingerprint to compare with. Leave out VM.Config.Options for read-only access.

      pveum role add ProxmoxNotesEditor -privs VM.Audit,VM.Config.Options
pveum user add proxmox-notes@pve -comment 'Proxmox Notes service'
pveum acl modify /vms -user proxmox-notes@pve -role ProxmoxNotesEditor
pveum user token add proxmox-notes@pve notes -privsep 1 -comment 'Proxmox Notes service'
pveum acl modify /vms -token 'proxmox-notes@pve!notes' -role ProxmoxNotesEditor
pvenode cert info
